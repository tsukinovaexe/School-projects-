# PHP Age Checker

A simple PHP school project that asks the user for their age and displays a different message depending on the age entered.

## What I practiced

- PHP forms
- `$_POST`
- PHP variables
- `if` statements
- `elseif` statements
- `else` statements
- Comparison operators
- Displaying results with `echo`

## How it works

The user enters their age into a form. PHP receives the value and checks it using different conditions.

The program gives a different response for different age ranges, from before birth to retirement.

## School assignment

This project was created as part of my ICT studies to practice PHP conditional statements and form input.
