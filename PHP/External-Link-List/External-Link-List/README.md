# External Link List

## Description

This project demonstrates how to create a link list that is stored in an external PHP file.

The link list can be included on multiple pages of a website. When the links are changed in the external file, the changes will appear on every page that uses the link list.

## Features

* External PHP link list
* Links to different websites
* Link list can be used on multiple pages
* Links open in a new browser tab

## Technologies

* PHP
* HTML
* CSS

## How It Works

The links are stored in a separate PHP file and included on the website using PHP.

The `index.php` page displays the external link list.
