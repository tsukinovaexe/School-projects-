# Multiplication Table

This task was completed using PHP.

The program asks the user to enter a number using a form. It then creates the multiplication table for that number, starting from 0 and continuing up to 100.

I used a `while` loop to repeat the calculations.

For example, if the user enters 5, the program displays:

5 * 0 = 0  
5 * 1 = 5  
5 * 2 = 10  
...  
5 * 100 = 500

The results are displayed on separate lines on the webpage.
