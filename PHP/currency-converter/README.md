# PHP Currency Converter

A simple PHP school project that converts an amount in euros into different currencies.

## What I practiced:

- PHP variables
- Arithmetic calculations
- `echo` statements
- Using exchange rates
- Displaying information on a webpage

## Currencies:

- EUR - Euro
- USD - US Dollar
- GBP - British Pound
- JPY - Japanese Yen
- SEK - Swedish Krona

## How it works

The amount in euros is stored in a PHP variable. The program then multiplies the amount by the exchange rate of each currency and displays the results.

The euro amount can be changed in the code, and all currency results will update automatically.
