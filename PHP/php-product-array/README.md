# PHP Product Array

A simple PHP school project that uses an array to store product names and displays selected products on a webpage.

## What I practiced

- PHP arrays
- Adding values to an array
- Accessing array values
- `echo` statements
- Basic HTML output

## How it works

The product names are stored in a PHP array. A new product is then added to the array, and several products are displayed on the webpage using their array positions.

## School assignment

This project was created as part of my ICT studies to practice PHP arrays and displaying array values.
